# Project Notes

## Typography

Use `Assets/Fonts/Minecraft.ttf` as the main UI/body pixel font at 16pt.

Use `Assets/Fonts/upheaval/upheavtt.ttf` as the project's bold-style pixel font at 20pt. It is already visually bold and has a 20pt base resolution, so prefer switching to this font for bold emphasis instead of relying on bold styling from `Assets/Fonts/Minecraft.ttf`.
